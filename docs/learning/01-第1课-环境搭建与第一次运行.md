## Step 0：打开终端

- 用 PyCharm：底部「Terminal」标签（推荐，后面一直用它）
- 或 Win 键 → 输入 PowerShell 回车
- 先切到工作目录：`cd D:\projects`
- 判断自己在哪：PowerShell 提示符前面就是当前路径

## Step 1：安装 uv（Python 包管理器，顺带管理 Python 版本）

PowerShell 执行：

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

装完**关掉终端重新打开**（让 PATH 生效），验证：

```powershell
uv --version
```

看到 `uv 0.x.x` 即成功。

**为什么用 uv：** OpenManus 要求 Python 3.12，而你机器上已经有别的 Python（PyCharm/Jupyter 在用）。uv 会**单独下载一个 3.12 放进项目专属虚拟环境**，完全不碰你现有的 Python——这是不动你现有配置的最安全做法，也是目前 Python 圈的主流新工具（面试聊到工程化可以提）。

## Step 3：创建虚拟环境并安装依赖

在 `OpenManus` 目录里：

```powershell
uv venv --python 3.12
```

- 第一次会自动下载 Python 3.12（几十 MB），看到 `Created virtual environment` 即成功
- 激活虚拟环境（PowerShell）：

```powershell
.venv\Scripts\Activate.ps1
```

成功标志：提示符前面多了 `(.venv)`。

- **新手第一大坑：忘记激活。** 每次新开终端、每次重开 PyCharm 都要重新激活一次
- 若 PowerShell 报「在此系统上禁止运行脚本」：用管理员身份打开 PowerShell 执行 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`，然后重试

安装依赖（用清华镜像加速，国内直连官方源会很慢）：

```powershell
uv pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

预计 3~10 分钟。结束后验证：

```powershell
python -c "import openai; print(openai.__version__)"
```

打印出版本号即成功。

## Step 4：写配置文件 config.toml（本课核心教学点）

```powershell
copy config\config.example.toml config\config.toml
```

用 PyCharm 打开 `config/config.toml`，找到 `[llm]` 段改成 DeepSeek：

```toml
[llm]
model = "deepseek-chat"
base_url = "https://api.deepseek.com"
api_key = "sk-把你的key粘贴在这里"
max_tokens = 4096
temperature = 0.0
```

**逐行讲人话（每行都是面试考点）：**

| 配置 | 含义 | 面试相关 |
|---|---|---|
| `model` | 用哪个模型。`deepseek-chat` 是 DeepSeek 的对话模型 | 模型选择 = 成本与能力的权衡 |
| `base_url` | API 服务地址。**关键概念：这叫「OpenAI 兼容 API」**——DeepSeek、智谱等几乎所有模型厂商都提供和 OpenAI 完全相同格式的接口，所以代码一行不改，换个地址换个 key 就换了模型供应商 | 高频考点：为什么国产 AI 项目都敢宣称"支持多模型切换" |
| `api_key` | 你的钥匙，等价于钱包 | 永不提交 git、不外发 |
| `max_tokens` | 单次回复最多生成多少 token，防止失控烧钱 | token 是计费和上下文窗口的计量单位 |
| `temperature` | 0=最稳定可复现，越高越"有创造性"。**工具调用场景必须低温**：模型一"发挥"就会把工具参数编错 | 高频考点：温度对工具调用的影响 |

保存后顺手验证安全（养成习惯）：终端执行 `git status`，确认输出里**没有** config.toml——OpenManus 已默认忽略它，你的 key 不会被传上去。

## Step 5：第一次运行

```powershell
python main.py
```

出现输入提示后，输入这个任务（不需要联网，用的是内置 Python 执行工具；任务采用考核官建议的版本——第 20 项必须真算、无法背答案，且只调单一工具、排错面最小）：

```
计算斐波那契数列第 20 项，并解释你写的代码逻辑
```

你会看到它循环打印类似这样的内容：

- **Thought**：我需要写一段 Python 代码来计算……（思考）
- **Action / 工具调用**：python_execute，参数是……（选择工具和参数）
- **Observation**：执行结果 1 1 2 3 5 ……（工具结果被喂回给模型）
- 然后是下一轮 Thought……直到它判断任务完成，自动停止

**对照上一课的术语：屏幕上这三段就是 ReAct 循环的"思考→行动→观察"。** 看完按 Ctrl+C 退出。

## 常见报错对照表

| 报错关键词 | 原因 | 处理 |
|---|---|---|
| `'python' 不是内部或外部命令` | 虚拟环境没激活 | 回 Step 3 执行激活命令，看到 `(.venv)` 再继续 |
| `禁止运行脚本 …Activate.ps1` | PowerShell 执行策略限制 | 见 Step 3 的放行命令 |
| 下载很慢 / 超时 | 用了国外默认源 | 确认命令带了 `-i https://pypi.tuna.tsinghua.edu.cn/simple` |
| `SSL: CERTIFICATE_VERIFY_FAILED` | 你这台机器的网络对证书吊销检查严格（我之前测试时也遇到过） | 清华镜像一般能避开；仍报错把完整报错发我 |
| `401 Unauthorized / AuthenticationError` | key 填错或账户没充值 | 检查 config.toml：sk- 开头是否完整、有没有多余空格 |
| `404 / model not found` | model 名拼错 | 必须是 `deepseek-chat` |
