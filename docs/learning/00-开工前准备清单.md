# 开工前准备清单（你亲手做，约 30 分钟）

> 用法：逐项打勾，全部完成后回对话里说「开工」。
> 这里只放**必须你本人做**的事（注册、实名、付款、建目录）；技术安装在第 1 课里我带你做。

## A. 账号与 API Key（15 分钟）

1. **DeepSeek 开放平台**（主力，便宜稳定）：https://platform.deepseek.com
   - 注册 → 实名认证 → 充值 10~20 元（整个项目周期够用，用不完）
   - 左侧「API Keys」→ 创建 → 复制以 `sk-` 开头的密钥
   - 临时存到本地记事本，别留在聊天记录里
2. **智谱开放平台**（备用，免费）：https://bigmodel.cn
   - 注册即有免费模型（GLM-4.5-Flash）和新用户 2000 万 tokens 额度
   - 同样建一个 API Key 备用（主 key 出问题时 30 秒就能切换）
3. 确认 GitHub 能登录（你简历里的 hl019 账号）

**Key 安全三条（面试也能聊的安全素养）：**

- 不发给任何人，**也不要贴进任何 AI 对话框**——Key 只填进本地配置文件
- 永远不提交到 git（OpenManus 已默认忽略 config.toml，第 1 课会带你验证）
- 一旦怀疑泄露：立刻去平台删除重建，一分钟的事

## B. 目录与磁盘（✅ 已完成：ZCode 已创建 `D:\projects` 并克隆好两个仓库；D 盘剩余 48.1GB 满足要求，E 盘只剩 4.4GB 但本项目不用它）

1. 在 D 盘建工作目录：`D:\projects`（就这一层，别套太深）
2. 确认 D 盘剩余空间 ≥ 10GB
3. 三个不要：**不放 OneDrive 同步目录、路径不要中文、不要空格**
   - 原因：OneDrive 会锁定同步中的文件导致安装报错；部分 Python 工具对非 ASCII 路径水土不服。这两个坑各能浪费你一小时

## C. 每次开工前的例行（2 分钟）

1. 关掉 VMware 虚拟机和不用的重软件
2. 任务管理器瞄一眼：可用内存 ≥ 4GB 就能开工（你现在的 5.1GB 没问题）
3. 第 1~3 周完全不需要 Docker；第 4 周装 Docker 时我会先带你设一个内存保险（.wslconfig）

## D. 现在明确不用装的（防止准备过度浪费时间）

| 东西 | 什么时候才需要 |
|---|---|
| Docker Desktop | 第 4 周部署阶段 |
| Playwright 浏览器 | 第 3 周浏览器自动化 |
| chromadb（向量库） | 第 3 周 RAG |
| 本地大模型 / 显卡环境 | 永远不用，全程调云端 API |
